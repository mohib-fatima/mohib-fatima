## Current Research

### Feedback-Induced Distribution Shift in Multilingual LLM Deployment
My current research examines **Feedback-Induced Distribution Shift (FIDS)**, a deployment-phase phenomenon in which model outputs and evaluation choices allow localized quality declines to persist while aggregate metrics remain stable.

The work characterizes three mechanisms, each backed by a formal proposition:
- **Aggregate Masking Effect (AME)** — locale-level quality regressions get averaged away by aggregate dashboards
- **Aspirational Deferral Lock (ADL)** — backlogs stop getting revisited once a metric crosses an acceptable threshold
- **Low-Resource Locale Collapse (LRLC)** — under-resourced locales get deprioritized every cycle, compounding degradation over time

It also proposes **RL-Stable Deployment (RLSD)**, an inference-time adaptation framework for responding to detected distribution-shift signals without requiring model retraining.
