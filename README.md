## Current Research

### Feedback-Induced Distribution Shift in Multilingual LLM Deployment

My current research examines **Feedback-Induced Distribution Shift (FIDS)**, a deployment-phase phenomenon in which model outputs influence subsequent user queries and progressively reshape the effective input distribution encountered by a deployed LLM.

The work characterizes three mechanisms:

- **Lexical Echo Amplification (LEA)**
- **Low-Resource Locale Collapse (LRLC)**
- **Intent-Anchor Drift (IAD)**

It also proposes **RL-Stable Deployment (RLSD)**, an inference-time adaptation framework for responding to detected distribution-shift signals without requiring model retraining.
